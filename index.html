Collega l'app a GitHub

Per salvare le ricerche e avviare "Cerca adesso", l'app ha bisogno di un permesso di GitHub. Si fa una volta sola su questo dispositivo.

  1. Apri questa pagina di GitHub ↗.

  2. In Token name scrivi Radar auto. In Expiration scegli la durata più lunga.

  3. In Repository access scegli Only select repositories e poi radar-auto-usate.

  4. In Permissions premi Add permissions, scegli Actions e imposta Read and write.

  5. Premi Generate token, copia il codice che inizia con github_pat_ e incollalo qui sotto.

Il codice resta solo in questo browser e serve solo per questo progetto.
