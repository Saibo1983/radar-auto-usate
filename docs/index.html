Installa l'app gratuita ntfy (Android o iPhone) e iscriviti a questo nome di canale. Usa un nome difficile da indovinare: chi lo conosce vede gli avvisi.

Collega a GitHub

  1. Salva qui le ricerche e imposta gli avvisi.

  2. Copia la configurazione qui sotto nel file config/ricerche.json del repository (apri il file su GitHub ↗).

  3. GitHub Actions esegue la ricerca ogni giorno all'orario scelto, confronta con gli annunci già visti e invia email e notifica push con i nuovi.

Il repository è pubblico, quindi email e canale push non sono inclusi qui sotto. Vanno nei Secrets del repository ↗ come EMAIL_TO e NTFY_TOPIC, insieme a SMTP_USER e SMTP_PASSWORD.
